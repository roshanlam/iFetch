Sign in to iCloud

iFetch never asks for your Apple ID password in this browser, and there is no field here to type one into. The server reads it from your computer’s keychain, exactly as the command line does. The only thing this page ever sends to iCloud is the six-digit code from your devices.

Apple just sent a code to your devices

This is normal and it happens every time a new session is created. Look at your iPhone, iPad or Mac: a notification says someone is trying to sign in, and after you allow it you get a six-digit code. Type that code here.

Digits only. If you mistype it, nothing is lost — you can just enter it again.

No code arrived? Use to start again.

    What your backups are missing

    With “Optimize Mac Storage” on, macOS can throw away the contents of any iCloud Drive file while leaving its name, its date and its size in place. Finder shows a 4 GB video; the disk holds nothing. Time Machine, Backblaze, Arq, Carbon Copy Cloner and rsync all copy the empty shell and report success. It only fails at restore time, when the original is gone.

    What disappeared from iCloud

    Every other check asks what your copy is missing. This one asks the opposite: what did iCloud have last time that it does not have now? A bad sync, a family member, a compromised account or one of Apple’s own bugs can quietly remove a file, and iCloud empties its Trash after about 30 days — so there is a clock on finding out.
